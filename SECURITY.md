# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability
If you discover a security vulnerability within EasyShop, please do not file a public issue.
Send an email to `yashgoelbsr@gmail.com` with:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if available)

All reports are acknowledged within 48 hours and investigated promptly.
